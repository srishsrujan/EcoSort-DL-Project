# Dataset Sources and Provenance Notes

Use only the source actually included in your final experiment. This file lists public examples that can help you choose or document a dataset; it is not evidence that those datasets were used.

## Public examples inspected during preparation

### TrashNet++

GitHub repository: https://github.com/AbdullahAlNoman20/TrashNet

The repository describes 2,600 images across cable, e-waste, glass, medical waste, metal, plastics and cans, and states a CC BY 4.0 license. Verify the repository and license yourself before use.

### TrashBox

GitHub repository: https://github.com/nikhilvenkatkumsetty/TrashBox

The repository describes 17,785 images across glass, plastic, metal, e-waste, cardboard, paper and medical waste.

### TrashNet (common six-class version)

One public GitHub implementation describes the six classes cardboard, glass, metal, paper, plastic and trash and references the original TrashNet dataset.

## Final provenance checklist

Record:

- Dataset name and exact URL.
- Download date.
- Dataset license and attribution requirement.
- Original number of images.
- Images removed as unreadable or duplicates.
- Your class mapping into the four EcoSort classes.
- Any additional images collected by phone.
- Train/validation/test split method and seed.
