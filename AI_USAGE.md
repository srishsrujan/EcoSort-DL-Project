# AI Usage Statement

This project was developed with AI assistance for code scaffolding, documentation drafting, debugging support, and model-architecture exploration. AI tools were used to help structure the repository, outline the training pipeline, propose validation steps, and refine the reporting and submission materials.

The human author reviewed every AI-generated suggestion before accepting it. All code paths, configuration changes, and technical claims were checked against the repository state and the actual validation results.

Verified human-controlled checks performed for this project include:

- confirming the dataset source, class mapping, and licensing constraints;
- reviewing the training and evaluation workflow before relying on its outputs;
- running the automated test suite and compile checks;
- checking generated metrics, confusion matrices, and model evidence for consistency;
- validating that summary claims in the report match the observed results;
- reviewing the final submission package for completeness.

AI-generated content was treated as a starting point, not as proof. The final project quality still depends on the human review, dataset validation, and technical verification performed in this repository.
