# AI Usage Statement

This project package was prepared with AI assistance for code scaffolding, documentation structure, debugging checks, and research-oriented dataset-source discovery.

Human-controlled steps that must be completed before submission:

- verify the actual dataset source, license and mapping;
- run training on the real labelled dataset;
- inspect metrics and confusion matrices;
- perform phone-camera tests;
- inspect at least 20 failure cases and write the failure reasons;
- verify that the deployed model is the same checkpoint whose metrics are reported;
- review all claims in the final report.

AI-generated code was smoke-checked with Python compilation and unit tests included in this repository. These checks do not substitute for the required real-data validation.
